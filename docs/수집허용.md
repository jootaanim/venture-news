# 자동 수집 허용 기록

robots.txt로 자동 수집을 막고 있지만, 기관에서 별도로 허용을 받아 수집하는 곳을 기록한다.
허용이 철회되거나 범위가 바뀌면 해당 수집기를 워크플로에서 빼고 이 문서를 고친다.

## IBK기업은행

- 대상: 은행공고 게시판 목록 https://www.ibk.co.kr/cyber/noticeListCyber.ibk?pageId=IR03010400
- 허용: 2026-11-27, 사이트 운영자가 기업은행에 요청해 허용 답변을 받음(답변 원문은 운영자가 보관)
- 수집 방식(scripts/collect_ibk.py)
  - 1시간마다 목록 1페이지만 읽는다(이미 저장한 글을 만나면 멈춤). 상세 페이지는 읽지 않는다.
  - 출자사업(위탁운용사 선정) 관련 글의 제목·등록일·상세 주소·첨부파일 정보를 저장한다.
  - 첨부파일: 2026-11-27 추가 허용. 출자계획 공고의 공고문 파일만 받아 접수마감일 등 일정을 뽑는다(scripts/extract_dates.py). 파일 원문은 저장하지 않는다.
  - User-Agent: `Mozilla/5.0 (compatible; venture-news-bot/0.1)`, 요청 간격 3초.
- robots.txt 현재 상태: `User-agent: * / Disallow: /` (허용 답변과 별개로 바뀌지 않음)

## 농업정책보험금융원(농림수산식품모태펀드)

- 대상: 공지사항 게시판 https://www.apfs.kr/front/board/boardContentsListPage.do?boardId=10026&menuId=41
- 허용: 2026-11-27, 사이트 운영자가 농금원에 요청해 허용 답변을 받음(답변 원문은 운영자가 보관)
- 수집 방식(scripts/collect_apfs.py)
  - 1시간마다 목록 1페이지(15건)만 읽는다(이미 저장한 글까지 오면 멈춤). 새 출자사업 글만 상세 페이지를 한 번 열어 첨부파일 주소를 저장한다.
  - 첨부파일: 2026-11-27 추가 허용. 출자계획 공고의 공고문 파일만 받아 접수마감일 등 일정을 뽑는다(scripts/extract_dates.py). 파일 원문은 저장하지 않는다.
  - User-Agent: `Mozilla/5.0 (compatible; venture-news-bot/0.1)`, 요청 간격 3초.
- robots.txt 현재 상태: `User-agent: * / Disallow: /`
