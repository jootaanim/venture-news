# 모험자본 뉴스 — 설계 메모 (2026-11-25)

## 확정 요구사항
- 독자: 출자기관/LP 담당자 / 첫 화면: 출자사업 일정 캘린더
- 콘텐츠: VC 투자·펀드 결성, 출자사업 공고·결과, 벤처기업 소식, 정책·규제
- 출처: 언론사 RSS, 출자기관 공식 공고, 공공 데이터
- AI: Claude API(Haiku급), 월 1만원 이하. 태그·기관·금액·분야 추출, 한 줄 요약
- 저작권: 제목 + 원문 링크 + 자체 요약만 노출
- 형태: 정적 사이트, GitHub Pages + Actions 매일 갱신, 공개 + RSS/.ics
- 디자인: 리서치/대시보드형 / 과거 데이터: 최근 1~2년

## 한국벤처투자(KVIC) 수집 가능성 조사 결과
- 출자사업공지 목록: `https://www.kvic.or.kr/notice/kvic-notice/investment-business-notice`
  - 서버 렌더링 HTML, 로그인·JS 불필요. 총 1,140건(2026-11-25 기준)
  - 페이지 이동: `?pageNo=N`
  - 행 구조: 번호 / `[카테고리]` / 첨부 / 제목(`board_view(id)`) / 날짜
  - 카테고리: 출자계획, 설명회, 질의응답, 접수현황, 서류결과, 1차결과, 선정결과, 기타
- 상세: `...investment-business-notice?id={id}`, 첨부: `/fileDown?boardDataNo={id}&idx={n}`
- **중요**: 본문에는 일정(접수 마감·심사일 등)이 거의 없고 첨부 PDF(공고문)에 있음
  → 캘린더 일정은 PDF 텍스트 추출 → Claude로 일정 필드 추출 파이프라인이 필요
- 공공데이터: KVIC 사이트에 'Open API' 메뉴가 있음 (펀드현황). 추후 확인

## 로컬 환경 (현재 PC)
- Python: Microsoft Store 스텁만 있고 실제 미설치 / Node, Git: 없음
- 파이프라인은 GitHub Actions(Python)에서 실행하므로 로컬 설치 없이도 가능.
  로컬 테스트를 원하면 Python 3.12와 Git 설치 필요.

## 데이터 스키마 (초안)
```json
{
  "id": "kvic-5242",
  "source": "한국벤처투자",
  "kind": "notice | article",
  "category": "출자계획",
  "title": "...",
  "url": "...",
  "published": "2026-11-20",
  "summary": "AI 한 줄 요약",
  "orgs": ["한국벤처투자"],
  "amount_krw": null,
  "sectors": [],
  "events": [{"type": "접수마감", "date": "2026-12-10", "basis": "공고문 PDF p.2"}]
}
```
- 일정 `events.type`: 공고, 접수마감, 서류심사, PT심사, 선정발표, 결성마감
- 일정 날짜를 못 찾으면 추정하지 않고 `null`(미정)로 둔다.
